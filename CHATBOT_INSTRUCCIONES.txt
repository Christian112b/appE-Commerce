¿QUÉ ES EL CHATBOT?
================================================================================

Es un asistente virtual integrado en el sitio web que responde automáticamente
a preguntas frecuentes de los clientes. Funciona con respuestas predeterminadas
basadas en palabras clave.

================================================================================
CÓMO USARLO (PARA CLIENTES)
================================================================================

1. Al entrar al sitio, verás un botón flotante naranja en la esquina inferior
   derecha con el ícono de un chat y un badge "¿Ayuda?"

2. Haz clic en el botón para abrir la ventana del chatbot

3. El bot te saludará automáticamente y te ofrecerá ayuda

4. Puedes:
   - Escribir tu pregunta en el campo de texto
   - Presionar Enter o hacer clic en el botón de enviar
   - Usar las sugerencias rápidas (Productos, Envíos, Pagos, Contacto)

5. El bot responderá automáticamente basándose en palabras clave

6. Para cerrar, haz clic en la X en la esquina superior derecha

================================================================================
PREGUNTAS QUE PUEDE RESPONDER
================================================================================

CATEGORÍAS SOPORTADAS:
----------------------
✅ Saludos: hola, buenos días, hey, etc.
✅ Productos: qué venden, catálogo, chocolates, dulces
✅ Precios: cuánto cuesta, precios, valor
✅ Envíos: tiempo de entrega, envío, delivery
✅ Horarios: cuándo abren, horarios de atención
✅ Ubicación: dónde están, dirección, sucursales
✅ Pagos: formas de pago, tarjeta, efectivo
✅ Contacto: teléfono, email, contactar
✅ Productos específicos: Tornillo, Princesa
✅ Despedidas: adiós, hasta luego, bye

================================================================================
CÓMO PERSONALIZAR (PARA DESARROLLADORES)
================================================================================

ARCHIVO: js/chatbot.js

1. AGREGAR NUEVAS CATEGORÍAS DE PREGUNTAS:
-----------------------------------------
En la propiedad 'knowledgeBase', agrega una nueva categoría:

nuevaCategoria: ['palabra1', 'palabra2', 'palabra3']

Ejemplo:
promociones: ['promoción', 'descuento', 'oferta', '2x1']


2. AGREGAR NUEVAS RESPUESTAS:
----------------------------
En la propiedad 'responses', agrega la respuesta correspondiente:

responses = {
    ...
    promociones: 'Texto de la respuesta sobre promociones...',
}


3. AGREGAR LÓGICA DE PROCESAMIENTO:
----------------------------------
En el método 'processMessage()', agrega la verificación:

if (this.matchKeywords(lowerMessage, this.knowledgeBase.promociones)) {
    return this.responses.promociones;
}


4. MODIFICAR PRODUCTOS DESTACADOS:
---------------------------------
En la propiedad 'featuredProducts', modifica el array:

featuredProducts = [
    { 
        name: 'Nombre Producto', 
        price: '$00.00', 
        description: 'Descripción' 
    },
    ...
]


5. CAMBIAR SUGERENCIAS RÁPIDAS:
------------------------------
En index.html (se genera dinámicamente en chatbot.js), modifica:

<button class="suggestion-btn" data-message="Tu mensaje">🎁 Texto</button>

O en el método createBotHTML() del archivo chatbot.js


6. PERSONALIZAR ESTILOS:
-----------------------
ARCHIVO: css/styles.css

Busca la sección "/* Chatbot Styles */" y modifica:
- Colores (usando variables CSS como --color-primary)
- Tamaños de fuentes
- Posiciones
- Animaciones

================================================================================
ESTRUCTURA DEL CÓDIGO
================================================================================

CLASE PRINCIPAL: ChatBot
-------------------------
- constructor(): Inicializa el bot
- init(): Configura todo
- createBotHTML(): Crea el HTML del widget
- setupEventListeners(): Configura eventos
- toggleChat(): Abre/cierra el chat
- handleSendMessage(): Procesa envío de mensajes
- processMessage(message): Analiza el mensaje y devuelve respuesta
- matchKeywords(message, keywords): Busca coincidencias
- addMessage(text, sender): Agrega mensaje al chat
- formatMessage(text): Formatea el texto
- showTyping(): Muestra indicador de escritura
- hideTyping(): Oculta indicador de escritura
- addWelcomeMessage(): Mensaje inicial
