🚀 CÓMO ABRIR EL PROYECTO
================================================================================

OPCIÓN 1: Usar Live Server (Recomendado)
-----------------------------------------
1. Abrir el proyecto en Visual Studio Code
2. Instalar la extensión "Live Server"
3. Click derecho en index.html
4. Seleccionar "Open with Live Server"
5. ¡El sitio se abrirá automáticamente en tu navegador!

OPCIÓN 2: Usar Python
----------------------
1. Abrir terminal en la carpeta del proyecto
2. Ejecutar: python -m http.server 8000
3. Abrir navegador en: http://localhost:8000

OPCIÓN 3: Usar PHP
------------------
1. Abrir terminal en la carpeta del proyecto
2. Ejecutar: php -S localhost:8000
3. Abrir navegador en: http://localhost:8000

⚠️ IMPORTANTE: No abrir directamente el archivo index.html haciendo doble click,
   ya que algunas funcionalidades requieren un servidor web.

================================================================================
🎯 FUNCIONALIDADES PRINCIPALES
================================================================================

1. CARRITO DE COMPRAS
   - Agregar productos: Click en el botón del carrito en cada producto
   - Ver carrito: Click en el ícono del carrito en la navegación
   - Modificar cantidades: Botones + y - en el carrito
   - Eliminar productos: Botón "Eliminar" en cada item
   - Checkout: Botón "Proceder al Pago"

2. FILTROS DE PRODUCTOS
   - Click en las categorías de la sección "Explora Nuestras Categorías"
   - O usar los botones de filtro en la sección "Productos"
   - Opciones: Todos, Chocolates, Caramelos, Presentaciones, Temporalidades

3. BÚSQUEDA DE PRODUCTOS
   - Buscar en tiempo real mientras escribes
   - Encuentra productos por nombre

4. PANEL DE ADMINISTRACIÓN
   - Gestión completa de productos (Crear, Editar, Eliminar)
   - Visualización de ventas y estadísticas
   - Generación de reportes (Diario, Semanal, Mensual, Anual)
   - Gestión de clientes

================================================================================
❓ PREGUNTAS FRECUENTES
================================================================================

P: ¿Los pedidos son reales?
R: No, este es un proyecto de demostración. Los pedidos son simulados.

P: ¿Se procesan pagos reales?
R: No, el proceso de checkout es simulado con fines educativos.

P: ¿Puedo agregar mis propios productos?
R: Sí, usa el panel de administración para agregar, editar o eliminar productos.

P: ¿Los datos se guardan en una base de datos?
R: No, actualmente se usa localStorage. Para un proyecto real, necesitarías
   implementar un backend con base de datos.

P: ¿Puedo personalizar los colores?
R: Sí, edita las variables CSS en css/styles.css o admin/css/admin.css

P: ¿Funciona sin internet?
R: Funciona localmente, pero necesita conexión para:
   - Cargar Font Awesome (iconos)
   - Cargar Google Fonts (tipografías)
   - Cargar Chart.js (gráficas del admin)

🐛 SOLUCIÓN DE PROBLEMAS

PROBLEMA: Las imágenes no cargan
SOLUCIÓN: Verifica que estés usando un servidor web, no abriendo el HTML directamente

PROBLEMA: El carrito no guarda los productos
SOLUCIÓN: Verifica que localStorage esté habilitado en tu navegador

PROBLEMA: No puedo acceder al panel de admin
SOLUCIÓN: Verifica las credenciales: admin / costanzo2024

PROBLEMA: Las animaciones no funcionan
SOLUCIÓN: Asegúrate de estar usando un navegador moderno actualizado

PROBLEMA: El menú móvil no funciona
SOLUCIÓN: Verifica que JavaScript esté habilitado en tu navegador
